# Audit run v1 validity note

Evidence label: **Superseded / invalidated by analysis-layer audit.**

The v1 run completed the read-only four-dataset scan and its raw aggregate
files remain unchanged under `runs/20261020-v1/`. Its report incorrectly used
the total-record field as the count of queries with at least one eligible edge,
so the strict/calibration eligibility columns in the v1 report were inflated.
The underlying per-query classifications were retained, but v1 must not be
used as the authoritative summary. A corrected rerun under the unchanged
protocol is recorded as v2.
